# herbaceous.net

The source for the website. It's a static site, generated by Parsley itself
(no, really — `build.pars` is a Parsley program).

## I want to edit…

| …the thing | edit this file |
| --- | --- |
| The **home page** | [`pages/home.pars`](pages/home.pars) |
| The **Why?** or **Get Started** pages | [`pages/why.md`](pages/why.md), [`pages/get-started.md`](pages/get-started.md) (plain markdown) |
| The **docs** (manuals, reference, cheatsheet) | the markdown in `../docs/` — the site renders it as-is |
| The header, footer, or page `<head>` | [`layout.pars`](layout.pars) |
| Styles | [`assets/site.css`](assets/site.css) |
| Client-side behaviour (theme toggle, search box) | [`assets/site.js`](assets/site.js) |
| The homepage code example | [`examples/csv-page.pars`](examples/csv-page.pars) |
| What gets built, or a new page/section | [`build.pars`](build.pars) |
| Build machinery (sidebars, search index, link rewriting) | [`lib.pars`](lib.pars) |

## Building

From this directory:

```sh
pars build.pars
```

Output lands in `dist/` (not checked in). To preview locally, serve it with
anything, e.g. `python3 -m http.server -d dist`.

Deploys happen automatically: pushing changes to `site/**` or `docs/**` on
`main` triggers `.github/workflows/site.yml`, which rebuilds `dist/` and
publishes it to GitHub Pages at <https://herbaceous.net>.
